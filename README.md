# calendar-tracker-ai

AI-assisted calendar tracking application built for CSCI471.

## Versions

- **v1** - Basic add/delete events
- **v2** - Recurring events support
- **v3** - Save/load events to JSON file
- **v4** - Reminders/notifications
- **v5** - Export to CSV

## How to run

```
python3 calendar.py
```

Requires Python 3.
